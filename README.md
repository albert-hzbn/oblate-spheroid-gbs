# Oblate-spheroidal shear transformation zone: analysis, data and simulations

Supporting code and data for

> A. Linda and K.A. Padmanabhan, *Analysis of an oblate-spheroidal shear transformation
> zone and its implications for grain boundary sliding and superplastic flow*
> (submitted to the Journal of the Mechanics and Physics of Solids).

The repository lets a reader check every number in the paper, regenerate every figure,
and repeat the molecular-dynamics (MD) calculations of Appendix A.

## Contents

| Folder | What it holds |
|---|---|
| `theory/` | `verify_numbers.py` recomputes the analytical results (Eshelby integrals, energy coefficients, far-field angular factor, slip-profile identities, kinetic example, 41-system statistics, tensor-strain correspondence). `figures.py` draws the main-text Figures 1-3 and Supporting Information Figures S1-S8. `data/systems_41.json` holds the 41 superplastic systems compared in the Supporting Information. |
| `md/` | LAMMPS inputs, structure builders, the Cu potential and the starting bicrystal structures for Appendix A (see `md/README.md`). |
| `analysis/` | Scripts that turn MD output into the Appendix results and Figures A.1-A.5 and S9. |
| `mesoscale/` | Grain-boundary-sliding rate law with the unit activation energy; comparison with the Cu-alloy data of Padmanabhan and Divinski (2024). |
| `results/` | Processed MD and mesoscale data used for every figure and table (stress-strain curves, flow stresses, dislocation content, quasi-static shear curves, NEB energy profiles, digitised experimental points, summaries). |
| `figures/` | The figures as they appear in the paper (`main/`, `si/`) and as regenerated by `theory/figures.py` (`theory/`). |

## Quick check (no simulations needed)

```bash
pip install -r requirements.txt
python theory/verify_numbers.py          # analytical results  -> results/theory_checks.json
python theory/figures.py                 # Figures 1-3, S1-S8  -> figures/theory/
python analysis/analyze_rate.py          # activation volumes and energy (Appendix A.4)
python analysis/appendix_figures.py      # Figures A.1-A.5     -> figures/main/
python analysis/stress_strain_figure.py  # Figure S9           -> figures/si/
python mesoscale/synthesis.py            # activation energies vs fitted values
python mesoscale/fullset_comparison.py   # 52-point strain-rate comparison (Figure A.3)
```

All of these run from the data in `results/` and `theory/data/` in a few minutes.

## Where each result comes from

| Paper item | Script | Data |
|---|---|---|
| Eshelby coefficients, Table 1, Figure 2 | `theory/verify_numbers.py`, `theory/figures.py` | analytic |
| Figure 1 (unit and stress sign map) | `theory/figures.py` | analytic |
| Figure 3, Figures S1-S8 | `theory/figures.py` | analytic; `theory/data/systems_41.json` |
| Figure A.1 (stacking-fault energy) | `analysis/appendix_figures.py` | `results/gsfe/` |
| Figure A.2 (quasi-static emission and NEB) | `analysis/appendix_figures.py` | `results/bicrystal_quasistatic/`, `results/neb/` |
| Figure A.3 (52-point strain-rate comparison) | `mesoscale/fullset_comparison.py` | `results/mesoscale/` |
| Figure A.4 (grain-size series) | `analysis/analyze_poly.py` | `results/poly_summary.json`, `results/ihp_fit.json` |
| Figure A.5 (activation volume and energy) | `analysis/analyze_rate.py` | `results/polycrystal/rate_*`, `results/rate_summary.json` |
| Figure S9 (stress-strain curves) | `analysis/stress_strain_figure.py` | `results/polycrystal/` |
| Table A.1 | the scripts above | `results/*.json` |

Figure numbers in the paper follow order of appearance; the file names in `figures/main/`
(`figA1_gsfe.pdf`, `figA4_emission.pdf`, ...) are the working names used by the scripts.

## Repeating the MD calculations

See `md/README.md`. The calculations need LAMMPS (tested with the 22 July 2025 release),
Atomsk for the polycrystals and OVITO 3.x (Python module) for the structural analysis.
Raw trajectories (about 200 GB) are not included; they can be regenerated with the inputs
here, and are available from the authors on request.

## External data

The experimental strain rates and stresses of the Cu-based superplastic alloy are those of
K.A. Padmanabhan and S.V. Divinski, Mater. Sci. Eng. A 908 (2024) 146713. The stresses were
digitised from Figure A1 of that paper (`mesoscale/digitize_kap2024_figA1.py`); the figure
image itself is not redistributed. The 41-system parameters are from K.R. Harisankar and
K.A. Padmanabhan, Mater. Sci. Eng. A 930 (2025) 148175, as transcribed in the Supporting
Information.

The Cu potential (`md/potential/Cu_mishin1.eam.alloy`) is that of Y. Mishin et al.,
Phys. Rev. B 63 (2001) 224106, as distributed by the NIST Interatomic Potentials Repository.
